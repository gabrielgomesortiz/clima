# Weather App

Aplicativo web que consulta o clima em tempo real usando a API do OpenWeatherMap. Mostra temperatura, clima, umidade e velocidade do vento de qualquer cidade.

## Link do Projeto
[Veja funcionando aqui](https://gabrielgomesortiz.github.io/clima/)

## Funcionalidades
- Consulta de temperatura em °C  
- Descrição do clima (céu limpo, nublado, chuva, etc.)  
- Umidade e velocidade do vento  
- Interface responsiva com animações  
- Tratamento de erro para localizações inválidas  

## Tecnologias
- HTML5, CSS3, JavaScript
- API OpenWeatherMap  

## Arquivos
- `index.html` – Estrutura do app  
- `index.css` – Estilos e animações  
- `index.js` – Lógica e requisições à API  
- `images/` – Ícones e imagens  

## Como usar
1. Clone o projeto  
2. Configure sua chave da API no `index.js`  
3. Abra `index.html` no navegador
